## Hi, I’m Yellowcooln

I build open-source tools around mesh radio, embedded hardware, and self-hosted infrastructure. Much of my work focuses on MeshCore and openHop, where I work across the full stack: firmware, radio hardware, repeaters, backend services, live maps, dashboards, Home Assistant integrations, and deployment tooling.

I enjoy turning rough ideas into projects people can actually install and depend on. That means testing on real radios and boards, packaging applications for platforms like Docker and Unraid, and seeing how everything behaves outside my own development setup. I care about reliable connections, useful metrics, clear interfaces, and software that stays manageable after the first install.

Most of my projects start because something feels missing, so I build what I think should exist. I self-host it, test it under real conditions, break a few things along the way, and share what works. If someone else finds it useful, great. If not, no big deal. It’s out there if someone needs it someday.
