Hi, I’m Yellowcooln

I build open-source tools around mesh radio, embedded hardware, and self-hosted infrastructure. Much of my work focuses on MeshCore and openHop, where I work across the full stack: firmware, radio hardware, repeaters, backend services, live maps, dashboards, Home Assistant integrations, and deployment tooling.

I enjoy turning rough ideas into projects people can actually install and depend on. That means testing with real radios and hardware, packaging applications for platforms like Docker and Unraid, and paying attention to how everything behaves outside a controlled development environment. I care about reliable connections, useful metrics, clear interfaces, and software that remains manageable after the first install.

Most of my projects start because I see a need for something and can’t find an existing option that does the job the way I think it should. I build what I need, self-host it, test it under real conditions, and share it when it works. If other people find it useful, great. If not, that’s fine too. It’s out there for whoever might need it later.
